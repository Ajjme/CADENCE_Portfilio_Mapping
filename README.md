# CADENCE Portfolio Mapping

Production Streamlit portfolio and Alternative Analysis interface over the CADENCE modeling system.

See the [dashboard guide](CADENCE/docs/streamlit.md) for Asset Portfolio, Alternative Analysis Results, Insurance View, controls, outputs, and code ownership.

From this repository root, start the combined dashboard with:

```shell
bash CADENCE/run_dashboard.sh
```

Use **http://localhost:8520/** for Asset Portfolio, Alternative Analysis Results, and Insurance View. Reuse this server across chats; stop it with Ctrl+C before restarting after code updates. Do not start separate ports for individual features.

See [CADENCE/README.md](CADENCE/README.md#streamlit-application) for installation, launch, and workflow documentation. The original mapping prototype remains in [Mapping_Application_CADENCE](Mapping_Application_CADENCE) as a visual reference.
